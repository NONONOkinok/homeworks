# 1st Case "Система аутентификации пользователя"

приложение на Python с графическим интерфейсом (Tkinter) для регистрации и входа пользователей.

## Кратко о возможностях
- Хранение пользователей в SQLite (`users.db`).
- Хэширование паролей через Argon2.
- Оценка стойкости паролей через `zxcvbn` (русские переводы — в `translations.py`).
- Поддержка Unicode в паролях: кириллица, иероглифы, эмодзи и др.
- Блокировка входа на 2 минуты после 3 неудачных попыток.

## Быстрый старт

```bash
make install   # установить зависимости
make run       # запустить приложение
make test      # запустить все тесты (pytest)
make test-cov  # тесты + отчёт о покрытии (терминал + htmlcov/)
